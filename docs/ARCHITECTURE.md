# 架构说明

控制面负责内容、播放单、发布与审计；播放器数据面只获取所属终端的签名清单并回传心跳/播出证明。当前社区版用 JSON 原子快照便于单机试用，企业部署可在不改变领域服务的前提下替换为 MySQL/PostgreSQL、对象存储、消息队列和 CDN。

```text
运营管理端 → HTTP API → 领域服务 → JSON/数据库
                          ↓
屏幕播放器 ← 签名 Manifest ← 发布计算器
     └──── 心跳 / 播出证明 ────┘
```

外设播放内核、Android 盒子或系统级开机自启属于硬件适配层；仓库提供浏览器播放器和协议实现，不宣称已经适配任意真实硬件。
